### 収録様式

この帳票は 1 レスポンスに複数の様式を含む（sheet_code `10040200` を 1 回取得すると下記が同時に返る）。

- 本葉: 様式ID `HOA420` → xpath ルート `//HOA420[@page='1']`
- 次葉: 様式ID `HOA430` → xpath ルート `//HOA430[@page='1']`

次葉は次葉ページが未使用の場合レスポンスに現れない。XTX(XML) では本葉・次葉は `<DATA>` 直下の兄弟要素として出力される（入れ子ではない）。
