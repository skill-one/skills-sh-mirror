# 別表一（青色・白色）と次葉

<!-- markdownlint-disable MD013 MD024 -->

複数の帳票を 1 ファイルにまとめている。帳票ごとに `##` 見出しで区切られ、
見出しの直下に `sheet_code` と `様式ID` がある。目的の帳票は `sheet_code` で検索する。
共通仕様（xpath 表記の規則・名前空間・共通ヘッダ）は [`index.md`](./index.md) を参照。

## 収録帳票

| sheet_code | 様式ID | 帳票名 |
| --- | --- | --- |
| `10100100` | `HOA112` | 別表一（青色）各事業年度の所得に係る申告書 |
| `10100101` | `HOA111` | 別表一(一)（白色）各事業年度の所得に係る申告書 - 普通法人(特定の医療法人を除く)・一般社団法人等及び人格のない社団等 |
| `10100102` | `HOA116` | 別表一次葉 |
| `10100102` | `HOA115` | 別表一(一)次葉（白色） |

## 別表一（青色）各事業年度の所得に係る申告書

- sheet_code: `10100100`
- 様式ID: `HOA112`
- 電子申告: e-Tax（国税）
- 取得API: `GET /hub/tax_return/corporate/sheet/national/{tax_return_id}/10100100`
- レスポンス: XTX(XML)
- xpath ルート: `//HOA112[@page='1']`
- 共通仕様（xpath 表記の規則・名前空間・共通ヘッダ）は [`index.md`](./index.md) を参照。
