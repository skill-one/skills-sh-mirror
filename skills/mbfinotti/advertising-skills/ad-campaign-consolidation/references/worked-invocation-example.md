# Worked Invocation Example

Input:

> "We run 14 search campaigns and 9 paid-social ad sets on about $9K/month, maybe 40 conversions total. Our agency built it years ago. What should we merge?"

Output: run the Interview first - the "why does each split exist" answer will likely reveal mostly archaeology. Then work the account:

1. Inventory the 23 branches.
2. Compute per-branch volume. At ~40 conversions across 23 branches, almost every branch fails the volume test.
3. Test each split against the preserve rules, classify, and apply the Evidence Gate.
4. Deliver the plan.

The delivered plan carries:

- A per-branch classification table.
- A target structure of few well-fed campaigns, with brand kept on its own budget.
- Segment knowledge moved into creative variants.
- A 3-phase migration starting with the unjustifiable splits.
- A measurement plan with the dip forecast, pass threshold, and rollback trigger.
