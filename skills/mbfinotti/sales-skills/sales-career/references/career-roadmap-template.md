# Career roadmap template

Fill every section; deliver only after the evidence audit passes at 100% and the quality gate passes 8/8. Build it section by section, validating each with the user before writing the next.

```
SALES CAREER ROADMAP - <name or "candidate">, <date>

SNAPSHOT
  Background     : <current position, per interview Q1>
  Target         : <role and seniority> in <B2B / B2C / both weighed>
  Date to hit    : <the date the result must land by>
  Geography      : <location, remote constraints, licensing jurisdiction if B2C>
  Comp priority  : <ceiling / balanced / stability>
  Proof on hand  : <quantified sales / quantified adjacent / none yet>

CHOSEN PATH (user-picked, not assumed)
  Path           : <one line>
  Why it fits    : <ties to the date, geography, comp priority>
  Ordering used  : <the efficiency line the menu was presented with>
  Deleted        : <path> - <the hard constraint that ruled it out>
                   (deleted before the menu, never ranked last)
  Rejected       : <path> - <why it lost the ranking, not a hard constraint>
  World          : <B2B / B2C>; advice marked (both) applies identically

BENCHMARK ANCHORS USED
  <figure> - <edition/date> - <publisher and figure type>
  (one line per number the roadmap relies on)

SKILL-GAP PLAN
  | Gap | Action | Proof artifact it produces | Target date |
  (each action ends in an artifact an interviewer or manager can see:
   a rehearsed mock call, a story bank, a methodology applied to a real
   or practice deal - never "study X" with no output)

EVIDENCE BANK (audited)
  | Claim, as you will say it | Audit status | Reframed from (if any) |
  (only claims that passed arithmetic + provenance + depth; reframes
   shown so the user remembers what they may NOT claim)

INTERVIEW READINESS
  [ ] STAR bank: 5 stories x 3 lengths, incl. a miss-and-recovery story
  [ ] Mock call rehearsed aloud, curveball handled, explicit close
  [ ] "Sell me this pen": qualify-first answer ready
  [ ] 30-60-90 plan drafted (if target employers request one)
  [ ] Brag book assembled, every number audit-passed
  [ ] Two diligence questions chosen for the panel

OFFER GATE (before accepting anything)
  [ ] Team-level attainment asked; answer or refusal recorded
  [ ] OTE re-valued at real attainment
  [ ] Percentile band built (sources + pull dates)
  [ ] B2C only: draw-terms checklist complete, in writing
  [ ] B2C only: 3-6 month runway confirmed

MILESTONES
  | Date | Milestone | Exit trigger if missed |
  (every milestone has a date; at least one exit trigger is named,
   e.g. "no documented AE-path conversation by month 12 -> external search")

KPIs (weekly)
  <applications -> screens rate, screens -> role-plays, role-plays -> offers,
   rehearsals done; in-role: pipeline sourced, next path-conversation date>

RE-ASSESSMENT
  Next review    : <date, or the memory-scheduled trigger>
  Re-route rule  : no movement after 4-6 weeks of executed actions
                   -> re-run path weighing
```

## Filled fragment (abbreviated example)

```
CHOSEN PATH (user-picked, not assumed)
  Path           : B2B SDR seat at a mid-market SaaS company, then AE track
  Why it fits    : 6-month date beats real-estate licensing + $8K
                   first-year median (verified, NAR 2026); stability
                   priority needs a salaried base
  Ordering used  : B2B SDR seat > adjacent-seat lateral (efficiency)
  Deleted        : Real estate - licensing exam does not fit the 6-month
                   date (newest-agent median $8,000, verified)
                   Straight-commission solar - under 3 months of runway
  Rejected       : CSM-adjacent lateral - one to two years slower to a
                   closing seat, no constraint broken
  World          : B2B; interview-prep advice marked (both)

EVIDENCE BANK (audited)
  | "Top 3 of 12 associates on conversion, ~22% vs store avg ~15%,
     4 straight months" | PASS | reframed from "best seller in the store" |
  | "Raised $18K of a $15K target leading a 6-person committee" | PASS | - |
```

The fragment shows the standard to hit:

- Deletions cite the hard constraint that removed the path before the menu existed.
- Rejections cite only where the path lost the ranking.
- Every evidence line shows a number that cross-multiplies, its audit status, and what inflated claim it replaced.

## Path selection - worked example

Career changer with quantified retail numbers, a 6-month date, stability priority:

- Deleted before the menu was built: licensed B2C entry. A stability priority and a 6-month date cannot survive a first year at an $8,000 median (NAR 2026). Record it as deleted with that constraint, not as a path ranked last.
- Path A - B2B SDR: salaried, structured ramp of ~3.1-3.2 months and median ~16 months in seat before AE promotion (Bridge Group); slowest to big money, lowest variance.
- Path B - CSM-adjacent entry, then lateral into a closing seat: one to two years slower to a closing seat, but leverages the service background and stays salaried throughout.

Recommend A, and show the deletion as a decision the user's own constraints made.
