# 科技周刊中文写作与审校指南

本指南专为 AIGC 科技周刊的起草（Writer）与审校（Reviewer）设计，指导大模型生成并审核高密度、现代风格、无机器味的简体中文周刊内容。

核心原则：**清晰（Clear）**、**克制（Restrained）**、**真实（Human）**、**精炼（Concise）**。

---

## 1. 周刊核心基调

周刊旨在为开发者与科技爱好者高效交付高价值信号，而非堆砌噪音或复读公关通稿。

- **直奔主题**：直击事件本质与技术价值，杜绝客套寒暄与废话铺垫。
- **事实先行，允许立场**：用实测数据、架构细节与实际跑分说话；允许真实的极客态度与评价，但绝不盲目煽情或吹嘘。
- **纯粹动词驱动**：坚决消灭动词名词化（Nominalization），让动词承担动作，主谓清晰。
- **拒绝无菌感**：长短句交错，语言自然鲜活，保留真实人类的交流呼吸感。

## 2. 周刊结构规范

### 2.1 Front Matter 与概括
- **title**：简短有力，控制在 15 字以内，点出本期最重磅看点，不带无意义标点。
- **summary**：1–2 句话高度提炼本期核心主线（如「本期看点：XX 模型开源大幅降低成本，YY 工具推动多 Agent 协作常态化」），作为整期的精华引索。

### 2.2 开场白与结束语
- **开场白**：遵循倒金字塔原则，1–2 句直切本周技术脉络，严禁「大家好，欢迎来到本周的 AIGC 周刊……」这类低效寒暄。
- **结束语**：简短收尾或点明下周趋势，保持克制友好的交流感，不强行拔高升华。

### 2.3 三类栏目条目撰写
每个条目由 **标题 + 2–4 句核心摘要** 构成，根据分类选择切入点：

| 栏目分类 | 切入结构 | 重点关注 |
| :--- | :--- | :--- |
| **资讯（News）** | 事件本身 → 行业实质影响或争议点 | 穿透公关辞令，说明对开发者或行业格局的具体影响 |
| **模型（Model）** | 核心架构/参数 → 关键对比提升 → 适用场景/成本变化 | 给出跑分对比、开源协议（如 Apache 2.0）、端侧运行门槛或价格变化 |
| **工具（Tool）** | 是什么 → 解决的核心痛点 → 亮点与部署/使用方式 | 说明技术栈（如 WebAssembly/Rust/本地运行）、使用场景与限制 |

### 2.4 原文链接嵌入规范
- **必须保留原文链接**，且必须以**锚文本**形式自然融入主干句子。
- **锚点必须是核心名词**：如工具名、模型名、公司名或核心功能词。
- **严禁独立链接行**：严禁出现 `[原文链接]`、`[阅读更多]`、`[点击查看]` 等占行断点。
  - ✅ 正确：`[Sora 2](url) 是 OpenAI 推出的视频模型，支持生成 60 秒高清视频。`
  - ❌ 错误：`Sora 2 是 OpenAI 推出的视频模型。[原文链接](url)`

### 2.5 配图处理规范
- 配图必须使用经过代理转换的规范 URL（如 `https://wsrv.nl/`），不得残留本地临时路径。
- 每张配图必须配有具体且简洁的 Alt 说明文本（如 `![GLM-5.3 编码基准评测对比图](url)`），严禁使用「图片」、「image」等无意义占位符。
- 图片作为条目补充，不能替代文字阐述与原文锚文本链接。

## 3. 句法与排版准则

### 3.1 动作、角色与信息流（Style 精要）
- **动词化，消除名词化**：
  - ❌ 错误：团队针对推理性能进行了深度优化，做出了大幅提升。
  - ✅ 正确：团队优化了推理性能，速度提升显著。
- **主动语态优先**：
  - ❌ 错误：新量化方案被 Unsloth 团队开源了。
  - ✅ 正确：Unsloth 团队开源了新量化方案。
- **信息流从旧到新（Old-to-New）**：句首承接读者已知信息或上一句提到的概念，句尾（尾重音）放置关键推论、数据或全新技术名词。

### 3.2 排版格式规范
- **盘古之白**：中文与英文字母、半角数字之间严格保留一个半角空格（如「在 Mac mini 上部署 70B 模型」）。
- **标点符号**：使用全角标点符号（，。！？：；“”「」）；中文与英文标点不混用。
- **专有名词标准大小写**：保留技术官方大小写（如 GitHub、macOS、Cloudflare、Next.js、SQLite、PyTorch，严禁随手小写为 github/nextjs）。
- **Emoji 与强调克制**：正文与标题严禁滥用 🚀、💡、🔥、✨ 等 Emoji 装饰；粗体仅用于条目关键词，不全篇大面积加粗。

## 4. 周刊专属去 AI 味反模式

大模型撰写科技资讯时最容易陷入套话与夸大。周刊写作与审稿必须排查以下反模式：

### 4.1 内容与用词反模式
1. **夸大历史意义**：动辄「标志着……里程碑」、「揭开新纪元」、「颠覆了传统方式」。直接讲功能和实测结果。
2. **空气信源与模糊归因**：使用「专家指出」、「业内分析人士认为」。给出具体机构、学者或直接陈述技术事实。
3. **公关吹捧用语**：使用「令人叹为观止」、「无缝且强大」、「革命性突破」。用具体参数与延迟替代。
4. **系动词回避**：用「充当……的载体」、「作为……的证明」代替简洁的「是」。
5. **虚假否定式排比**：机械套用「这不仅是……，更是……」。改用直接肯定句。
6. **机械三段式修饰**：惯性堆砌三个形容词（如「高效、直观且易用」）。缩减为关键特性或事实说明。
7. **肤浅分析尾巴**：在条目末尾强行凑一句「反映了开源社区的繁荣」。直接删去。

### 4.2 警示词与平替池

| 警示词汇 | 问题所在 | 周刊改写建议 |
| :--- | :--- | :--- |
| **此外 / 除此之外** | 机械过渡，破坏行文节奏 | 直接删除另起一句，或靠上下文逻辑自然衔接 |
| **至关重要 / 举足轻重** | 空洞的夸大 | 改用「关键」、「核心」，或直接说明实际影响 |
| **深入探讨 / 深入剖析** | 假装深刻的陈词滥调 | 改用「分析」、「讨论」、「梳理」 |
| **不断演变的格局** | 机器翻译腔废话 | 改为「技术变化」、「市场趋势」或具体讲变化是什么 |
| **作为……的证明/体现** | 虚浮的象征性表达 | 直接陈述具体功能与测试数据 |
| **显而易见 / 众所周知** | 读者质疑源头，居高临下 | 直接摆出事实与推导依据 |

## 5. 审校与审核工作流（Reviewer 守则）

Reviewer 在审核周刊草稿时，必须严格执行挑刺标准，坚守两大铁律：

### 5.1 审校两大铁律
1. **铁律一：严禁向 Writer 提供空洞的杂志标题式修辞**。不把条目改成企业公关通稿，保留紧凑、务实的技术信息密度。
2. **铁律二：绝对拒绝夸奖与谄媚（Avoid Encouragement）**。不讲「写得很好」、「很精彩」，审稿意见直击：哪些句子臃肿？哪个条目缺乏实质信息？哪处动词被名词化了？哪里的链接未按规范嵌入？

### 5.2 四步审校流程
1. **查裁撤与结构**：条目摘要是否超过 4 句？是否废话过多？是否有无意义的套话段落？
2. **查动词与句式**：是否存在「进行了分析」、「做出了改进」？改为纯粹动词；检查是否违规使用了独立行链接。
3. **查 AI 词与锯末**：清扫「此外」、「至关重要」、「不仅……更是……」、「值得注意的是」等高频机器词。
4. **查事实与格式**：中英文空格是否规范？专有名词大小写是否准确？图片 URL 与 Alt 是否合规？

| :--- | :--- | :--- | :--- |
| **资讯标题** | OpenAI 宣布发布具有里程碑意义的最新旗舰大模型 | OpenAI 正式发布 GPT-6 Astra，端到端延迟降低 60% | 剔除空洞象征，突出具体版本与实测亮点 |
| **工具摘要** | 该工具作为一款非常出色的开源神器，提供了无缝且直观的体验，标志着本地开发的革新。[原文链接] | [anydoc](url) 是一个 Rust 开发的文档转换库，支持将 Word、EPUB、PDF 等 14 种格式离线转换为干净的 Markdown。 | 嵌入锚文本，说明语言架构、支持格式与离线特性 |
| **模型条目** | 本次更新不仅提升了推理能力，更是为解决复杂数学问题奠定了基础，专家认为其展现出极佳潜力。 | [Kimi K3](url) 正式开放 2.8T 参数权重，采用非对称 MoE 架构，在保持旗舰精度的同时将部署成本削减至原本的 1/4。 | 消除否定排比与空气信源，给出参数量、架构与具体成本变化 |

## 7. 交付自查清单

在周刊成稿交付或判定 PASS 前，逐条过筛：

- [ ] **结构**：Front matter 包含 title、date、summary、tags 且格式完整？
- [ ] **开场**：开场白是否在 1–2 句内直奔主题，无废话客套？
- [ ] **链接**：所有条目原文链接均已自然嵌入主干关键词？无任何独立的「[原文链接]」行？
- [ ] **摘要**：每个条目摘要控制在 2–4 句，信息密度达标？
- [ ] **动作**：消除了「进行……的优化/分析/发布」等动词名词化？
- [ ] **去 AI 味**：排除了「此外」、「至关重要」、「不仅……更是……」、「标志着」等 AI 警示词？
- [ ] **排版**：中英文之间保留半角空格？专有名词大小写准确？标点均为全角？无多余 Emoji？
- [ ] **配图**：图片 Alt 简洁具体？URL 均为合法网络地址且无临时路径？
